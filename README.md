---

## 🤔 왜 만들었나요?

헬스를 오래 한 사람일수록 무거운 무게로 운동하는데, 그만큼 **피로가 쌓이고 다칠 위험**도 커집니다.

이걸 막는 방법 중 하나가 **VBT(Velocity-Based Training, 속도 기반 훈련)** 입니다.
바벨을 들어 올리는 **속도**를 보면 지금 몸 상태가 어떤지, 언제 멈춰야 하는지 알 수 있습니다.
- 속도가 평소보다 빠르다 → 컨디션이 좋으니 조금 더 무겁게
- 속도가 눈에 띄게 느려진다 → 지쳤다는 신호, 여기서 멈추기

문제는 속도를 재려면 **수십~수백만 원짜리 전문 장비**가 필요하다는 것이었습니다.
베이트핏은 이 역할을 **휴대폰 카메라**로 대신합니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 📷 **카메라로 속도 측정** | 운동하는 모습을 찍으면, AI가 화면 속 **바벨을 찾아 따라가며** 들어 올리는 속도를 계산합니다 |
| 🧪 **나의 기준 측정 (테스트)** | 여러 무게로 몇 번 들어 보면, "무게가 늘수록 속도가 얼마나 느려지는지"를 계산해 **최대로 들 수 있는 무게(1RM)** 를 추정합니다 |
| 📋 **루틴 추천** | 목표(근력 향상·근비대·지구력 향상)와 측정 결과에 맞춰 오늘의 무게와 세트를 추천합니다 |
| 📊 **운동 기록과 결과** | 세트별 속도, 주간 운동량 그래프, 운동 후 리뷰를 보여 줍니다 |
| 📚 **운동 가이드** | 운동 종류별 자세 안내와 라이브러리 |

## 🛠️ 어떻게 만들었나요?

```
📱 휴대폰 앱 (Flutter)                       🖥️ 서버 (Node.js)
 ├─ 카메라 영상                                ├─ 사용자·운동 기록 저장 (MySQL)
 ├─ AI 모델이 바벨 위치 인식 (YOLO)   ──────▶  ├─ 무게–속도 관계 계산 (회귀 분석)
 └─ 프레임마다 위치 변화 → 속도 계산           └─ 1RM 추정, 루틴 추천
```

- **바벨 인식**: 사물 인식 AI 모델(YOLOv5·v8)을 휴대폰 안에서 바로 돌립니다. 바벨을 찾도록 **직접 학습시킨 모델**을 함께 사용했습니다.
- **속도 계산**: 영상의 각 장면에서 바벨이 얼마나 움직였는지로 속도를 구합니다.
- **무게–속도 관계**: 여러 무게에서 잰 속도를 하나의 직선으로 이어(선형 회귀) 최대 중량을 추정합니다.

**사용 기술** — Flutter(Dart) · TensorFlow Lite · YOLOv5/v8 · Node.js · Express · MySQL

### 폴더 구성

| 폴더 | 설명 |
|---|---|
| `app/vvfit/` | **Flutter 앱 본체** (화면: `lib/screens`, 인식 모델: `assets/*.tflite`) |
| `app/` (그 외) | 앱에서 쓰는 비전 플러그인(flutter_vision) |
| `server/` | Express API 서버 (`api/routes`: 로그인·운동·루틴·VBT 계산) |

### 앱 실행

```bash
cd app/vvfit
flutter pub get
flutter run
```
Android Studio에서 `app/vvfit` 폴더를 열어 실행해도 됩니다.

### 서버 실행

```bash
cd server
npm install
node app.js
```
MySQL 접속 정보는 `server/api/db/dbConfig.js`에서 설정합니다.
